# Lens: polish

## Question

What small UX/consistency/copy improvements raise quality without redefining the product?

## In

- Empty states, spacing, labels, consistency with existing patterns

## Out

- New features, architecture changes, AI-slop rewrites of working code

## Steps

1. Scan UI or user-facing surfaces for the target.
2. Prefer existing design patterns in-repo.
3. Cap 8; after fixes, cheap `working` re-smoke if `working` was in the requested set or polish fixes touched primary path.

## Hard stop

No product redefine. No silent always-on harness hook/rule rewrites.
